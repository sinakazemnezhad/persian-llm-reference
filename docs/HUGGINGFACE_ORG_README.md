# Hugging Face organization README (paste into org profile)

**Persian LLM Reference** is an open, bilingual atlas for Persian (Farsi) language models — models, datasets, benchmarks, and leaderboards with sourced records and honest verification gates.

We work **alongside** community curators ([Awesome-Persian-LLM](https://github.com/MohammadHeydari/Awesome-Persian-LLM)), public leaderboards (MIZAN, PartAI, Matina), and the teams who publish weights and papers.
